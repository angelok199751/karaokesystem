# KaraokeForge

Десктопное приложение для автоматической генерации караоке с оценкой вокала.

## Возможности

- 🎤 Автоматическая сепарация вокала из любой песни (Demucs)
- 📝 Forced alignment текста с аудио (WhisperX)
- 🎵 Извлечение pitch contour оригинального вокала (CREPE)
- 🎯 Оценка точности попадания по нотам в реальном времени
- ⏱️ Обратный отсчёт перед каждой фразой
- 🌐 Работает полностью офлайн после первичной загрузки моделей

## Требования

- Python 3.11+
- ffmpeg (системная зависимость)
- GPU NVIDIA (опционально, ускоряет обработку в 5-10×)

## Быстрый старт

### Linux/macOS

```bash
make build
./dist/KaraokeForge/KaraokeForge
```

### Windows

```bat
build.bat
dist\KaraokeForge\KaraokeForge.exe
```

## Структура проекта

```
karaoke-forge/
├── src/                    # Исходный код
│   ├── pipeline/           # Пайплайн генерации караоке
│   ├── player/             # Плеер и оценка вокала
│   ├── ui/                 # Пользовательский интерфейс
│   └── utils/              # Утилиты
├── models/                 # ML-модели (скачиваются автоматически)
├── assets/                 # Ресурсы приложения
├── tests/                  # Тесты
└── requirements.txt        # Python-зависимости
```
